This browser has no Web MIDI. Use Chrome or Edge on a desktop computer.

Custom scales (U1, U2, U3)

Click keys to build a scale. The root is always included and a scale needs at least 5 notes. Scales are stored relative to the root, so the TB's root buttons can play them in any key. The keys use the same colours as the TB: while you edit, all of its pads show the scale as 12 columns of semitones from the root (root white, scale notes in colour, other notes dark), and its screen shows the slot and the notes.

Settings backup

Saves the current settings, the 8 presets and the 3 user scales to a file, and puts them back later (for example after installing new firmware, which clears them).

External memory backup

Copies the TB's 16 MB memory chip (the original firmware's data) to a file. Read-only: the firmware cannot write to that chip. It reads everything twice and only calls the copy verified if both reads match. Takes several minutes per read; the TB does not play while it runs.

The TB pauses its notes for about a second after each command from this page, so it is best not to play while saving. Protocol: TheoryBoard SysEx v1 (docs/tb-sysex.md).
