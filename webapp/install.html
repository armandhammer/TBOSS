TBOSS Installer

Installs TBOSS on a TheoryBoard THY333 over USB, using the board's own update mode. Works in Chrome or Edge on Windows, macOS, Linux and ChromeOS. Nothing else to install.

This browser cannot talk to USB devices. Please use Chrome or Edge on a computer (not a phone or tablet).
Before you install. Installing replaces the board's firmware (flash area 6-11 only; the board's own start-up loader is never touched, so you can always repeat the installation). To go back to the original firmware, use the manufacturer's update utility and update file (see the installation guide).

1Firmware

Looking for the firmware…

2Keep your settings (only if TBOSS is already installed)

Installing clears TBOSS's saved settings, presets, user scales, favorites, progressions, chord sets and step patterns. With the board connected and running normally, click Save settings: this page keeps a copy, downloads it as a file too, and puts everything back after installing. Skip this step on a board with the original firmware.

3Start the board in update mode

  1. Unplug the TheoryBoard's USB cable, and its power adapter if one is plugged in (the board must be fully off).
  2. On the left (chord) half, press and hold the top-left and bottom-left pads (orange below).
  3. Keep holding them and plug the USB cable back in. Keep holding for about 3 seconds, then let go.

In update mode the screen shows the TheoryBoard logo and the five buttons below the screen stay lit. If the board starts normally instead (pads light up, it plays), unplug and try again.

4Connect

Click Connect, choose TheoryBoard in the list Chrome shows, then click Connect in that dialog.

5Install

Do not unplug the board until this page says it is done (about a minute).

6Check and play

The board restarts by itself and appears on the computer as the MIDI device TheoryBoard MIDI. This page then asks it for its version and puts your saved settings back.

Read the manual, and open the editor for custom scales and backups.
